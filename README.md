# Maktab — د مکتب د مدیریت سیستم

A modern Flutter school-management application with a Pashto-first, RTL interface and an offline-first local database.

## Design direction
- Premium editorial look inspired by the Adabi Khazana app: warm ivory surfaces, deep forest-green accents, subtle gold details, rounded cards, spacious typography.
- Pashto-first RTL layout, with planned Dari and English localization.
- Responsive layouts for phones and tablets.
- Light and dark themes.

## Planned modules
Dashboard; Students; Teachers; Classes & Sections; Subjects; Attendance; Examinations; Results & report cards; Fees and finance; Library; Timetable; Staff; Parents; Notifications; Documents; Certificates; Holidays; Reports; Users & permissions; School settings; Backup & restore; Academic years; discipline, awards, assets, laboratory and transport.

## Technology
- Flutter / Dart
- SQLite (sqflite) for offline-first data
- Local preferences for language and theme
- PDF/Excel export and backup/restore are planned follow-up milestones.

## Development
1. Install Flutter stable.
2. Run `flutter pub get`.
3. Run `flutter run`.

> This repository is being built incrementally. Do not enter real student or staff personal data until authentication, access controls, backup and privacy safeguards are implemented and tested.
